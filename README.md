## Featured Projects

### 🌦️ WeatherIQ — Real-Time Weather Data ETL Pipeline `(Owner)`
End-to-end data engineering pipeline that ingests live weather data from the OpenWeatherMap API through a 5-stage ETL process (extract → transform → validate → load → report), persists to MySQL via SQLAlchemy ORM, and visualizes it on an interactive Streamlit dashboard.
- 6-rule data validation engine with severity tagging and structured JSON reports
- Derived feature engineering (heat index, comfort-level classification)
- Multi-sheet Excel/CSV analytical exports, rotating pipeline logs
- **Live demo:** [weather-data-etl-pipeline.onrender.com](https://weather-data-etl-pipeline.onrender.com/)
- **Repo:** [github.com/Arpitapaaul/weather-data-etl-pipeline](https://github.com/Arpitapaaul/weather-data-etl-pipeline)
